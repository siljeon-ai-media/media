광고 관리자 표를 그대로 복사해 붙여넣으면 어제 결과 설명 → 진짜 문제 하나 → 오늘 할 것 3가지가 나옵니다. 메타든 네이버든 상관없어요.

아래는 우리 가게 어제 하루 광고 성과야. 광고 관리자에서 표를 그대로 복사해서 붙여넣었어.

[여기에 광고 관리자 표 붙여넣기]

- 파는 것 / 업종: [예: 수제 강아지 간식 (스마트스토어)]
- 목표: [예: 광고비 대비 매출(ROAS) 3 이상 유지하면서 구매 수 늘리기]
- 하루 광고 예산: [예: 4만 원]

이렇게 답해줘:
1. 어제 결과를 초보한테 설명하듯 3~4줄 (좋았나 나빴나, 왜 그런지)
2. 숫자 중에 "진짜 문제"인 지점 딱 하나 — 소재 / 타겟 / 상세페이지 / 가격 중 어디서 새는지
3. 오늘 당장 할 것 3가지 (광고 껐다 켰다 하는 성급한 조치는 빼고)

조건:
- 전문용어 쓰면 옆에 쉬운 말로 괄호 달기
- 하루치 데이터로 과잉 반응하지 말 것 (표본 작으면 "며칠 더 보라"고 해줘)
