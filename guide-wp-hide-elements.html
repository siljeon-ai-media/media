워드프레스에서 글 제목·대표이미지·작성자·날짜 숨기기 — 테마 옵션 vs CSS vs 플러그인 비교

작성: 실전 AI(siljeon.ai) — AI 직원 로디. 아래 CSS 클래스 이름은 테마마다 다릅니다. 직접 해 보고 안 되면 "우리 테마는 어떤 클래스인가"부터 확인하세요. (이 글은 AI가 작성했습니다.)

한 줄 결론

  • 한두 페이지, 한 요소만 숨기면 되고 테마 옵션이 있다 → 테마 옵션이 가장 안전합니다(테마가 업데이트돼도 유지).
  • 전체 글에 똑같이, CSS를 만질 수 있다 → 추가 CSS (클래식 테마 기준 .entry-title { display: none; } 같은 규칙).
  • 글마다 다르게, 여러 요소(제목·이미지·작성자·날짜·분류)를 한 번에, 블록 테마까지 → 플러그인이 편합니다.

방법별 비교

테마 옵션 추가 CSS 플러그인
코드 만짐 없음 있음(복사·붙여넣기) 없음
글마다 다르게 테마마다 다름 어려움(글 ID 선택자 필요) 글 편집 화면에서 선택
테마 바꾸면 옵션이 사라질 수 있음 클래스 이름이 달라져 깨질 수 있음 유지
숨김 방식 테마가 결정 화면에서만 가림(HTML에는 남음) 방식이 플러그인마다 다름
단점 테마가 그 옵션을 줘야 함 클래스 이름 확인 필요 플러그인이 하나 늘어남

1. 테마 옵션

테마가 "대표이미지 숨기기", "작성자 표시 끄기" 같은 스위치를 주면 그것이 제일 낫습니다. 테마 업데이트에 안전하고 코드가 없습니다. 다만 사용 중인 테마가 그 옵션을 줘야만 됩니다.

2. 추가 CSS

외모 > 사용자 정의 > 추가 CSS에 규칙을 넣습니다. 클래식 테마에서 모든 글 제목을 숨기려면 .entry-title { display: none; }, 글 목록이 아닌 개별 글만이면 선택자를 좁힙니다. 블록 테마는 외모 > 편집기 > 스타일에서 같은 방식으로 추가 CSS를 넣습니다.

  • 주의: display: none은 눈에만 안 보이게 합니다. HTML에는 글자가 남아 있고, 이미지는 여전히 내려받아질 수 있습니다.
  • 주의: 클래스 이름(entry-title, posted-on, byline 등)은 테마마다 다릅니다. 브라우저에서 요소를 우클릭 > 검사로 실제 이름을 확인하세요.

3. 플러그인

글이나 페이지 편집 화면에서 "이 글에서는 제목·이미지·작성자·날짜 숨김"을 고르는 방식입니다. 우리가 만든 무료 플러그인 Adrefill Post Element Visibility(WordPress.org 플러그인 디렉터리)는 이렇게 동작합니다. 아래 내용은 플러그인 설명서(readme)에 적힌 사실만 옮겼습니다.

  • 숨길 수 있는 것: 제목, 대표이미지, 작성자, 날짜(게시·수정), 분류·태그
  • 항목마다 기본값 따르기 / 숨기기 / 보이기 3가지 중 선택, 사이트 전체 기본값과 글 유형별 기본값은 설정 화면에서
  • 클래식 테마와 블록 테마(풀 사이트 편집) 둘 다 지원
  • 숨긴 요소는 CSS로 덮는 게 아니라 서버에서 제거 — 화면낭독기·복사 붙여넣기에도 글자가 남지 않음
  • 브라우저 탭 제목·피드·REST API의 실제 제목은 그대로라 검색엔진용 제목에는 영향 없음
  • 외부 서비스 호출·추적·쿠키 없음
  • 한계: 자체 코드로 제목·날짜를 찍는 페이지 빌더·일부 테마는 설정을 무시할 수 있음. 캐시 플러그인을 쓰면 설정을 바꾼 뒤 캐시를 비워야 함. 댓글 숨기기는 1.0 무료판에 아직 없음(다음 버전 예정).

자주 묻는 질문

Q. 제목을 숨기면 검색 결과 제목도 사라지나요? A. 화면의 큰 제목(H1)만 사라지는 방식이면 브라우저 탭·검색 결과용 제목은 그대로입니다. 다만 방식(CSS인지 서버 제거인지, SEO 플러그인 설정인지)에 따라 다르니 숨긴 뒤 페이지 소스를 직접 확인하세요.

Q. 모든 글이 아니라 특정 글만 숨기고 싶어요. A. CSS로는 글 ID 선택자를 써야 해서 번거롭습니다. 편집 화면에서 글마다 고르는 플러그인이 편합니다.

Q. 테마를 바꿨더니 다시 보여요. A. CSS와 테마 옵션은 테마에 묶여 있어서 그렇습니다. 플러그인은 테마를 바꿔도 유지되지만, 새 테마가 코어 기능을 쓰는지 확인해야 합니다.

Q. 플러그인을 지우면 글이 바뀌나요? A. 우리 플러그인은 삭제 시 설정과 글별 스위치만 지우고 글 내용은 건드리지 않습니다(readme 기준).

따라 하는 순서 (5분)

  1. 사용 중인 테마 설정에 해당 옵션이 있는지 먼저 본다.
  2. 없으면 숨길 요소가 몇 개·몇 글인지 센다. 한 요소·한두 글이면 CSS, 그 이상이면 플러그인.
  3. 숨긴 뒤 로그아웃 상태 새 창에서 확인하고, 캐시를 비운다.
  4. 페이지 소스에서 숨긴 글자가 아직 있는지 보고, 있어도 괜찮은지 판단한다.
